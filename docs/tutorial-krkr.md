# 用 EngAixt 汉化 KiriKiri 游戏（图文教程）

以《ライムライト・レモネードジャム》（ゆずソフト）为例。其他 KiriKiri / 吉里吉里引擎的游戏步骤基本一致。

## 准备工作

- Windows 10 / 11 x64
- EngAixt 发布版（官网 <https://engaixt.com/> 或 GitHub Releases）
- 游戏已经安装或解压到本地目录
- 云端翻译需要先在「设置 → 云端模型」填对应服务商的 API Key；也可以安装本地模型组件离线翻译

## 第 1 步：打开 EngAixt，导入游戏

![EngAixt 主界面](../images/krkr-tutorial/01-main.png)

把游戏主程序（`.exe`）或整个游戏文件夹拖进窗口中间的虚线区域，也可以点右侧「选择文件」。

支持 `.exe`、游戏文件夹、`.zip` / `.rar` / `.7z`、Steam 快捷方式等。导入后 EngAixt 会自动识别引擎，不需要手动选择。

## 第 2 步：选择游戏主程序

![选择游戏主程序](../images/krkr-tutorial/02-select-game.png)

在弹出的文件选择框里选中游戏主程序。

- 常见命名：`游戏名.exe`、`limelight_lj.exe`、`startup.exe` 这类
- **不要选** `install.exe`、`uninstall.exe`、`ファイル破損チェックツール.exe` 等辅助程序
- 选中后双击，或点「打开」确认

## 第 3 步：确认引擎识别，选择翻译方式

![识别引擎](../images/krkr-tutorial/03-engine-detected.png)

导入成功后，路径下方会显示识别出的引擎，例如「吉里吉里 / KiriKiri」。

这时有两种做法：

| 方式 | 适合场景 | 结果 |
| --- | --- | --- |
| **开始翻译** | 想一次性汉化，以后直接启动 | 生成汉化补丁/启动器，游戏文件被替换或注入 |
| **实时翻译** | 想边玩边翻，不改动游戏文件 | 运行时捕获文本并翻译，字幕窗口显示 |

大多数 KiriKiri 游戏选「开始翻译」即可。受保护封包（带签名、自定义索引）的游戏，EngAixt 会自动改用运行时 Hook 的方式投递译文。

## 第 4 步：解包与提取文本

![提取文本](../images/krkr-tutorial/04-extract.png)

KiriKiri 游戏会先解包脚本封包（`data.xp3`、`scn.xp3` 等），再解析 PSB 脚本里的台词。

进度条下方会显示类似 `KRKR：解析脚本文本 (35/138)` 的信息，表示正在处理第 35 个、共 138 个脚本文件。

这一步只读取文本，不会修改游戏原始文件。

## 第 5 步：翻译

![翻译中](../images/krkr-tutorial/05-translate.png)

翻译阶段会显示：

- 总文本条数（示例：67,921 条）
- 已翻译条数
- 涉及文件数（示例：138 个）

云端模型会按批次并发请求；本地模型只在本机运行，不产生 API 费用。

> 翻译期间可以继续用电脑，进度条到 100% 即完成。若中途关闭，重新运行会从检查点续翻，不会重复翻译已完成的条目。

## 第 6 步：完成，进入游戏验证

![游戏内效果](../images/krkr-tutorial/06-in-game.png)

翻译完成后，EngAixt 会自动回填译文并启动游戏（可在设置里关闭「完成后自动启动」）。

- KiriKiri 游戏会在游戏目录生成 `启动汉化版.exe`，以后从它启动即可
- 正文、旁白、选项应该都是中文
- 如果游戏目录里同时存在旧的 `启动汉化版.bat`，新版本会自动移除，只保留一个入口

## 常见问题

**长句还是日文？**

重新运行一次。EngAixt 会复用检查点，只补翻空译（模型解析失败、校验失败留下的条目），不会重复翻译已有译文。

**标题菜单、存档按钮这些 UI 文本没翻？**

这些是游戏系统文本，来源分散在 UI 脚本/资源里，当前提取范围主要覆盖剧情脚本。后续版本会逐步扩展。

**翻译后游戏打不开 / 黑屏？**

用左侧「诊断报告」导出报告，附上游戏名和日志反馈。诊断信息不包含游戏资源和完整译文。

**想换回原版？**

左侧「卸载汉化」会恢复被修改的文件（EngAixt 在回填前会做备份）。

## 补充说明

KiriKiri 游戏的封包保护方式不同：

- 普通封包：直接生成 `patch.xp3` 覆盖层，引擎原生读取
- 带签名/自定义索引的封包：引擎不读 `patch.xp3`，EngAixt 自动改用运行时 Hook，启动器会变成 `启动汉化版.exe` 并加载译文地图
- 极端情况（exe 内嵌哈希校验）：无法修改封包，只能走运行时方案

这些判断由 EngAixt 自动完成，不需要手动选。
